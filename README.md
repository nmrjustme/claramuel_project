# Mt. ClaRamuel Resort & Events Place - Booking System

A comprehensive web-based booking and management system developed for the Mt. ClaRamuel Resort & Events Place. This platform streamlines the reservation process for guests while providing resort staff with a powerful administrative dashboard to manage bookings, payments, and resort operations.

## Features

* **Real-Time Booking System:** Robust reservation logic that prevents double-booking and handles room/event availability dynamically.
* **Payment Integration:** Secure, production-ready payment processing for guest reservations and deposits.
* **Administrative Dashboard:** A centralized control panel for staff to manage customer reservations, update room statuses, and track revenue.
* **Responsive UI/UX:** A modern, mobile-friendly interface ensuring a seamless booking experience across all devices.

## Tech Stack

* **Backend:** PHP / Laravel
* **Frontend:** Tailwind CSS
* **Database:** MySQL
